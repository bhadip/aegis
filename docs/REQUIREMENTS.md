# System Requirements
- **Host OS**: Ubuntu 22.04 LTS or Debian 12.
- **Docker**: Version 24.0+ with `docker-compose` plugin.
- **Network**: Static local IP or reliable DNS resolution (e.g., `100.75.220.84`).
- **MT5 Prerequisites**: "Allow Algo Trading" and "Allow WebRequest for listed URL" (add `http://<YOUR_HOST_IP>:8000`) must be enabled.
