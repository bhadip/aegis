## v0.14.1 Known Issues

### Economic Events PAST Display
**Severity**: Low  
**Status**: Expected behavior  
**Description**: PAST event may not appear early in the week (Monday/Tuesday) if no high-impact USD events have occurred yet. The rolling 10-day event store populates after the first event elapses.  
**Workaround**: None required; will resolve automatically after next high-impact USD release.

### Logo/Favicon Missing
**Severity**: Low  
**Status**: Requires manual setup  
**Description**: Logo and favicon not displaying in browser.  
**Resolution**: Copy logo.png and favicon.ico to web-ui/ directory and restart container.
