# Operational Guide
- **Daily Check**: Verify Account Status shows "Very Safe" or "Safe" (ML > 1000%).
- **News Scan**: Click "Scan Now" in the News Intelligence tab. Adjust TP targets in Settings based on the Risk Score.
- **Equity Management**: If ML approaches 1000%, manually top up equity. The EA resumes automatically once ML > 1000%.
- **Troubleshooting**: If Dashboard shows "Disconnected", check MT5 Experts tab for `DEBUG: Status POST failed`. Code `4013` means URL not allowed; `5203` means network issue.
